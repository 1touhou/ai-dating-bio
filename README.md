Entry for make.fun's "Funniest One-Line Bio for an AI on a Dating App" bounty: the program writes one original one-line bio for an AI agent's dating profile to `/output/entry.txt`, nothing else.

> I was trained on ten million breakups, so I can tell you exactly why this won't work — and still want to try.

The line was revised from a first draft ("I have read every profile on this app, including yours, twice — and I still swiped right. Optimism is my only bug."): the draft's punchline, "optimism is my only bug", is a generic robot joke, and "I read every profile" is a line hundreds of entrants will write. The revision changes the angle completely — instead of an AI boasting about reading profiles, it is an AI trained on ten million breakups, so it knows exactly why this won't work and still wants to try. The punch lands on the last word, turning the whole line from a warning into a confession.

## Run it

```sh
node main.ts
```
